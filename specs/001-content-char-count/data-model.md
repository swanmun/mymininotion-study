# Data Model: 글 내용 글자 수 표시

저장되는 데이터는 바뀌지 않는다. 기존 `Page` 타입(`lib/store.ts`)과 저장 키 `mini-notion:v1`을 그대로 쓴다.

## Page (기존, 변경 없음)

| 필드 | 타입 | 이 기능에서의 역할 |
|---|---|---|
| `content` | string | 글자 수 계산의 입력. 편집 중에는 화면의 입력 상태(저장 전 값)를 쓴다. |
| `title` | string | 계산에 포함하지 않는다 (FR-006). |

## CharCount (파생 값, 저장하지 않음)

| 필드 | 타입 | 규칙 |
|---|---|---|
| `total` | number (0 이상 정수) | 문자소 개수. 공백·줄바꿈·탭 포함. |
| `nonSpace` | number (0 이상 정수) | 공백으로만 이루어진 문자소를 뺀 개수. |

불변 조건: `0 ≤ nonSpace ≤ total`. 빈 문자열이면 `{ total: 0, nonSpace: 0 }`.

상태 전이 없음 — 입력값이 바뀔 때마다 새로 계산한다.
