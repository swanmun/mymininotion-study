# Quickstart: 글 내용 글자 수 표시 검증

## 준비

```bash
npm install
```

## 자동 검증

```bash
npm test
```

기대 결과:
- `lib/charCount.test.ts`: [계약 1절](contracts/char-count.md) 표의 모든 행 통과.
- `app/pages/[id]/page.test.tsx`: 아래 수동 시나리오 1~4와 같은 내용이 통과.
- 전체 스위트 통과, 출력에 에러·경고 없음 (헌법 품질 관문).

## 수동 검증

```bash
npm run dev
```

1. `/login`에서 로그인한 뒤 `/page`로 새 글을 만든다 → 내용 입력칸 아래 `글자 수 0 · 공백 제외 0`.
2. 내용에 `안녕 하세요` 입력 → `글자 수 6 · 공백 제외 5`. 한 글자 지우기 → `글자 수 5 · 공백 제외 4`.
3. Enter로 줄을 바꾸고 `👍🏽` 입력 → 공백 포함 +2, 공백 제외 +1.
4. 1초 기다려 "■ 저장됨"이 된 뒤 새로고침 → 같은 숫자가 바로 보인다.
5. 1,000자 이상 붙여 넣기 → 쉼표가 들어간 숫자, 입력이 끊기지 않음.
6. 860px 이하로 창을 줄여도 글자 수가 입력칸 아래에 그대로 보인다.
7. 사이드바에서 다른 글을 누르면 그 글의 글자 수로 바뀐다.
