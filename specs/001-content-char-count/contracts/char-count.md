# Contract: 글자 수 계산과 표시

## 1. 함수 계약 — `lib/charCount.ts`

```ts
export function countChars(text: string): { total: number; nonSpace: number };
```

| 입력 | total | nonSpace | 근거 |
|---|---|---|---|
| `""` | 0 | 0 | 빈 내용 |
| `"안녕 하세요"` | 6 | 5 | US1-2, US2-1 |
| `"가 나\n다"` | 5 | 3 | US2-2 (줄바꿈 = 공백) |
| `"   "` | 3 | 0 | US2-3 |
| `"a\tb"` | 3 | 2 | 탭 = 공백 |
| `"a\r\nb"` | 3 | 2 | CRLF = 1자 |
| `"👍🏽🇰🇷"` | 2 | 2 | 이모지 수식·국기 = 각 1자 |
| `"é"` | 1 | 1 | 결합 문자 = 1자 |
| `"한글"` | 2 | 2 | 완성형 한글은 자모로 쪼개지 않음 |

- 부수 효과 없음, 입력을 바꾸지 않음.
- 기대값은 위 표처럼 손으로 센 리터럴로 테스트한다 (원칙 II).

## 2. UI 계약 — 글 상세 화면 (`app/pages/[id]/page.tsx`)

- 위치: 내용 입력칸(`textarea`, placeholder "여기에 내용을 입력하세요...") 바로 다음 형제 요소.
- 문구: `글자 수 {total} · 공백 제외 {nonSpace}` — 숫자는 `ko-KR` 세 자리 쉼표 (예: `글자 수 1,234 · 공백 제외 1,000`).
- 갱신: 내용 입력칸의 값이 바뀌는 즉시. 자동 저장(1초)과 무관.
- 초기값: 글을 열면 저장된 `content` 기준.
- 다른 글로 이동: 새 글 기준으로 다시 계산 (Editor가 글마다 다시 마운트됨).
- 표시 안 함: "글을 찾을 수 없습니다" 화면.
- 접근성: 일반 텍스트, `aria-live` 없음.
- 스타일: `.ws-count num` — 12px, `var(--fg-2)`, tabular-nums.
